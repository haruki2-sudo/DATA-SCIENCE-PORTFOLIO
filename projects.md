# Projects

Coursework and lab exercises from my Data Science and Deep Learning classes, with notebooks
that walk through the full process from theory to working code.

## Deep Learning Fundamentals

- **[Laboratory Task 2 — Forward Pass & Error](laboratory_task_2.ipynb)**
  Manually computing a single forward pass through a small neural network (3 inputs, 2 hidden
  units, 1 output) using ReLU activation, and calculating the resulting error.

- **[Laboratory Task 3 — Forward & Backward Propagation](laboratory_task_3.ipynb)**
  Extending Task 2 with a full backward pass computing error signals, gradients, and updating
  the network's weights and biases by hand using gradient descent.

- **[Laboratory Task 4 — Linear Regression in PyTorch](laboratory_task_4.ipynb)**
  Training a small feed-forward regression model (2 fully connected layers, MSE loss, SGD,
  batch size 8, 1000 epochs) on the sklearn Diabetes dataset, with loss curves and a
  predicted-vs-actual evaluation plot.
